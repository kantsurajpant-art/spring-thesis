# Revised project report

Everything here is generated by `scripts/build_report.py` from `src/report.md`, `numbers.json` and `src/references.json`.
Edit `src/report.md` (text) and re-run the build; do not edit the generated `.tex` or `.docx` by hand.

| Path | What it is |
|---|---|
| `overleaf_upload.zip` | **Upload this to Overleaf** (New Project → Upload Project). Compiler: pdfLaTeX; BibTeX runs automatically. |
| `overleaf/` | The same files unzipped: `main.tex`, `references.bib`, `figures/` |
| `figures/` | The 20 report figures on their own, numbered as in the report, with `CAPTIONS.md` (caption + source file of each) |
| `Project_Report_Revised.docx` | MS Word version of the same text. After opening: right-click the table of contents → *Update Field*. |
| `numbers.json` | Every statistic quoted in the report, collected from the notebook outputs |
| `reference_check.csv` | Each reference checked against Crossref (title, authors, year, journal, DOI) |
| `claims_check.csv` | Each number quoted from the literature checked against the cited paper's abstract |
| `src/report.md` | The report source text (numbers are `{{placeholders}}`) |
| `src/references_input.json` | The reference list to verify; `src/references.json` is the verified metadata; `src/abstracts.json` the abstracts used |
| `src/assets/` | KU logo and study-area map (map converted from the EMF in the submitted report) |
