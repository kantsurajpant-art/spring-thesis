# Spring Drying Analysis: ERA5-Land climate + Random Forest

ME project and thesis code (Kathmandu University, Masters in Computer Engineering). Field-surveyed springs in the Roshi Khola
watershed (3,287; 727 dried, 2,560 active) are classified as dried or active from ERA5-Land climate features (the 15-year mean
and Mann-Kendall Sen's slope of temperature, dewpoint, precipitation and potential evaporation) plus the perennial/seasonal
attribute, following *Revised Proposal 16th July*, Section 7.

**Main result (Model 3, fixed 2009–2023 window):** test accuracy 0.719, F1 0.476, ROC-AUC 0.748; shuffled 5-fold CV F1
0.511 ± 0.023; ROC-AUC 0.630 when whole climate grid cells are held out. Drought-dried vs active springs (Model 3b): ROC-AUC 0.854.
The ~0.99 scores of Models 1, 2 and 3 (Version A) are a leakage artefact, documented in the report.

## Notebooks (run in order)

| Notebook | Content |
|---|---|
| `00_dataset_overview` | class balance, drying years, survey dates, reported cause of drying, data-quality checks, descriptive figures, external springs, augmentation size |
| `01_climate_features` | ERA5-Land extraction; Version A (label-conditional) and Version B (fixed 2009–2023) features; distribution figures |
| `02_model1_exploratory` | Model 1: 29 predictors, Version A (integer-cast bug of the submitted version fixed) |
| `03_model2_refined` | Model 2: 25 predictors, Version A (re-created; original code was not archived) |
| `04_model3_version_a` | Model 3 predictors with the leaky Version A window |
| `05_model3_final` | **Model 3** (fixed window), comparisons, **Model 3b** (drought-dried labels), new-area test, lookup-table baseline, leakage diagnostic |

The notebooks are generated by `scripts/build_notebooks.py`; edit that script rather than the notebooks.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Data is found automatically in `../Project Preperation Rough/` (NetCDF, analysis CSV) and `../9-credit Project/document for
vscode format/` (raw survey export). To use another location, set `$env:SPRING_DATA_DIR = "D:\path\to\data"`.

## Run everything and rebuild the report

```powershell
python scripts\build_notebooks.py
cd notebooks; foreach ($nb in Get-ChildItem 0*.ipynb) { python -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=3600 $nb }; cd ..
python scripts\make_flowchart.py
python scripts\export_report_numbers.py
python scripts\check_references.py      # needs internet (Crossref)
python scripts\build_report.py
python scripts\check_claims.py
```

All random seeds are fixed (`random_state = 42`), so re-running reproduces every number.
